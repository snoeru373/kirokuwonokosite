## やり方・手順の詳細

### ステップ1 — ChatGPTで記事の下書きを作る

```
# プロンプト例（チャットに貼り付け）

「50代がUbuntuでローカルAI環境を作った実体験について、note向けの記事を下書きして。
箇条書きではなく、読者に寄り添う口語調にして。
段落はそれぞれ300文字程度で、見出しをH2まで入れること。」
```

出力されたものをコピーし、自分の経験談を追加・修正します。

### ステップ2 — Canvaでカバー画像を作る

1. [Canva](https://www.canva.com/) にアクセスして無料アカウント作成
2. 検索バーに「ブログ カバー」または「note cover」と入力
3. テンプレートを選んで、タイトル/著者名を編集
4. 「Download」→ PNG形式で保存

### ステップ3 — noteに投稿する

1. [note](https://note.com/) にログインし「新規記事」を開く
2. ChatGPTの出力+自分の修正した本文をペースト
3. Canvaで作ったカバー画像をドラッグ&ドロップして追加
4. タグ（#ローカルAI #Ubuntu #50代 #実体験）を付けて公開

## FAQ

### Q1. Canva無料版で著作権の問題はありませんか？
A: しません。テンプレートと素材はCanvaライセンスに従って利用できます（再配布はNG）。

A: 技術的には可能ですが、note読者にとって「AIが書いた感」が強く出るので、必ず自分の言葉で修正してください。
