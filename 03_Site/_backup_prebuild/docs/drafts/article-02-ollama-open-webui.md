## はじめに: なぜOllama + Open WebUIなのか

ChatGPTやClaudeをはじめとするクラウドAIは非常に便利ですが、50代として使う中で次のような悩みを持たないでしょうか。

1. **毎月の利用料が高い**
   - ChatGPT Plus: 月額2,000円程度
   - Claude Pro: 月額2,200円程度
   - 2つ使ったら月3,000〜4,000円。年間で何万円にもなります

2. **自分のデータが外部に出るのが不安**
   - ファイルをアップロードする度に、その情報がどこに保存されるのか分からない
   - 会社機密のメモや個人情報を扱う場合、クラウドに乗せるのは抵抗がある

3. **ネットがない場所で使いたい**
   - 災害時などの通信断で使えなくなる
   - 外出先でのオフライン利用ができない

私自身も「まずは自分のPC上でAIを動かしてみる」ことにしました。50代からの挑戦ですが、実は思ったよりハードルが低いことが分かりました。

今回はOllamaとOpen WebUIの両方を使って実際に何ができて何ができないのか、実体験を交えて解説します。

| 求めるもの | ◎向いている | △向かない |
|-----------|------------|----------|
| コストを抑えたい | ✅ ¥0（電気代のみ） | ❌ クラウドAIは月額¥2,000〜 |
| データを外部に出したくない | ✅ ローカル完結 | ❌ サーバー乗せてる |
| オフラインで使いたい | ✅ 通信不要 | ❌ インターネット必須 |

> **TL;DR（まとめ）**: ローカルAI(Ollama)×ブラウザUI(Open WebUI)は、コスト¥0・オフライン可・プライバシー確保の点で素晴らしい。ただしPC性能（特にVRAM/メモリ）が必要。「すぐ使いたい」にはクラウドAI、長く使いたいにはローカルAIがおすすめ。

## 私がOllama + Open WebUIを選んだ理由（50代の視点から）

### 理由1：月額料金を抑えたい
50代で副業を考えていると、初期投資を抑えたい気持ちがあります。

| サービス | 月額 | 年額 |
|---------|------|------|
| ChatGPT Plus | ¥2,000 | ¥24,000 |
| Claude Pro | ¥2,200 | ¥26,400 |
| Copilot | ¥1,080 | ¥12,960 |
| **Ollama + Open WebUI** | **¥0** | **¥0**（電気代のみ） |

この差は小さくありません。年間で5万円以上のコストカットになります。

### 理由2：Ubuntu環境が既に整っている
私の環境は次の通りです。

| 項目 | スペック |
|------|---------|
| PC | GMKtec EVO-X2 AI |
| メモリ | 96GB |
| VRAM | 48GB（GPU内蔵） |
| OS | Ubuntu 24.04 LTS |
| ストレージ | NVMe SSD 1TB以上 |

VRAMが48GBもあるおかげで、比較的大きなモデルでも動作します。しかし「最初はVRAM少なめで試す」方が安全です。

### 理由3：プライバシー重視
- 自分のメモや資料を外部に出したくない
- 会社の機密情報をAIに処理させたい場合
- 個人情報を含むファイルを読み込ませたい

## Ollamaとは何か（概要とインストール）

Ollamaは、ローカル環境でAIモデルを動かすための無料ツールです。

### メリット
- モデルのDL・実行がワンコマンドで完了する（例: `ollama pull llama2`）
- ローカルのブラウザやAPIからアクセス可能
- 多彩なオープンモデル（Llama、Mistral、Qwenなど）に対応
- Open WebUIと連携してWeb UIとして使える

### インストール方法（Ubuntuの場合）

```bash
# Ollamaのインストール
curl -fsSL https://ollama.com/install.sh | sh

# モデルをダウンロード（例: llama2）
ollama pull llama3.2:1b  # メモリ少なくて始めたいならまずこれを

# Ollamaが動いているか確認
curl http://localhost:11434/api/version
```

### おすすめモデル5選（VRAM別推奨）

| VRAM容量 | おすすめモデル | パラメータ数の目安 | 特徴 |
|---------|---------------|-----------------|------|
| 4GB以下 | llama3.2:1b / phi3:mini | 1B〜3B | とにかく動かしたい場合 |
| 8GB程度 | gptoss:22b-q4_K_M | ~20B | コストパフォーマンス良い |
| 16GB程度 | mistral-large:123b-instruct-q4_K_M | 123B | より高度な対話可能 |
| 48GB（私用） | qwen2.5:72b | 72B | ローカルでは最高級。ただし重い |

> **私の体験**: Qwen2.5-72bは動作が非常に重く、チャットの応答に10〜30秒ほどかかります。「速さと精度」のバランスならQwen2.5:32b-q4_K_Mがおすすめ。（8月確認でq4_quantized版を推奨）

## Open WebUIとは何か（概要と連携方法）

Open WebUIはOllamaと連携して動くブラウザベースのフロントエンドです。ChatGPTのような画面で使えます。

### メリット
- ChatGPTに似たUIでチャット操作が可能
- モデルの切り替えが容易
- チャット履歴の管理が簡単
- ファイルアップロードでPDF等を読み込ませられる（マルチモーダル対応版）

### インストール & 連携方法（Ubuntu + Docker）

```bash
# Dockerのインストール（まだでない場合）
sudo apt update && sudo apt install -y docker.io docker-compose-plugin
sudo systemctl enable --now docker

# Open WebUIの起動
docker run -d -p 3000:8080 --name=open-webui --restart=always \
  -v open-webui:/app/backend/data \
  -e OLLAMA_BASE_URL=http://host.docker.internal:11434 \
  ghcr.io/open-webui/open-webui:main
```

アクセスURL: `http://localhost:3000`

> **私の体験**: まず初回の接続で「Ollamaに接続できません」とエラーが出ました。原因は`OLLAMA_BASE_URL=http://localhost:11434`の指定が間違っていたことでした（Docker内から見た「localhost」がホストPCではない）。解決策として`http://host.docker.internal:11434`に変えるとつながりました。（8月修正）

## 実際に試してできたこと（できることリスト）

### 1. テキストの要約 ✅

ある程度の長さの記事をOllamaに読んで、要約を出しました。

**私が実際にやってみた例**:
- 4,000文字の記事 → 500字程度の要約を20秒ほどで作成
- ファイルアップロード（PDF）→ Ollamaが内容を把握し、質問に回答可能

ただし注意：長すぎる文書（1万字超など）の場合、要約の精度が落ちることがあります。その時は分割して入れると良いです。

### 2. コード生成と解説 ✅

PythonやBashのスクリプトをOllamaに書かせて、さらにコードの内容を説明させられました。

**実際に私が試した例**:
- 「UbuntuでGitの自動バックアップスクリプトを書いてください」→ Bashで7行程度の回答を得た
- 書いたコードの説明を「このコードが何をしているか教えてください」→ 文法的に正しく解説（ただし一部古い情報の記述もあった）

> **私の体験**: Llama2よりMistralの方がコード生成の精度が高かったです。またQwen2.5はPython特に得意で、複雑な関数でも正しく動きました。（8月更新）

### 3. ファイルの読み込み ✅（Open WebUIから）

Open WebUIからファイルをドラッグ＆ドロップして、Ollamaに内容を読み込ませることができます。PDFだけでなくテキストファイル (.md, .txt) もOK。

**私が実際にやってみた例**:
- Obsidianに保存したMarkdownファイルをアップロード → Ollamaが内容を理解し要約・質問に回答
- Gitで管理しているコードのリポジトリのREADME.mdをアップロード → プロジェクト概要把握

### 4. マルチモーダル（画像理解） ✅ （Ollama + Open WebUI Multimodal版のみ）

一部のモデル（Llama3.2 Multimodalなど）は画像も読み込めます。ただし：
- DockerでOpen WebUI Multimodal版を起動する必要があります
- VRAMが必要です（8GB以上推奨）

**私の体験**: 50代なので写真の解説や手書きメモの文字起こしに使えるかも？と思いましたが、まだ試していないため次の機会に。（今度Ubuntu上で試したい）

### 5. リアルタイム検索 ❌ （Ollama単体では不可）

OllamaはローカルAIなので、**最新のニュースや天候情報を直接取得できません。**

ただしOpen WebUIのExtensions（拡張機能）を使えば、ブラウザを通じて検索結果を取得し、それをAIに渡すことは可能です。（8月追記：Open WebUI 0.5以降でAPI連携が可能になりました）

## 実際に試してできなかったこと（できないことリスト）

### 1. リアルタイム情報 ✅（ただし制限あり）

前述の通り、最新のニュースや天気情報を直接取得できません。

**私が実際に体験したこと**:
- 「今日の東京の天気を教えてください」と聞いたら「最新の情報は提供できません」と返答
- これはローカルAIの仕様上の制約で、インターネットに繋がない限り無理です

> **回避策**: Open WebUIのExtensions機能で、外部API（天気APIや検索API）を呼び出すカスタムコードを書けば可能。ただしこれは「高度な設定」になるため初心者向きではありません。（8月確認でAPI連携方法も紹介します）

### 2. GPU負荷が重い ⚠️

VRAMが少ないマシンで重いモデルを動かそうとすると、動作が極端に重くなることがあります。

**私が実際に体験したこと**:
- Qwen2.5の72b-q4_K_M版を試した時、チャットの応答に10〜20秒ほどかかった（8月追記では32bに切替えて約3秒になりました）
- さらにVRAM不足でエラーが出る場合もあります。この時は`ollama list`で現在のVRAM使用量を確認

### 3. モデルのアップデートの手間 ⚠️

クラウドAIなら最新のモデルが自動更新されますが、ローカルAIの場合は自分でDLする必要があります。

**私が実際に味わったこと**:
- Qwen2.5が正式リリースされた時、新しいバージョンに切り替えるのに「ollama pull qwen2.5:72b-q4_K_M」を手動実行する必要があった（数分で完了）

## つまずいたポイント（ハマりポイント①〜⑤）

### ハマリ①：VRAM不足でモデルが動かない

原因は、自分が選んだモデルのパラメータ数がVRAMを超えていたため。特に「大きいモデル＝高性能」と思い込みで重いモデルを選んでしまいました。（50代特有の「大きければ良い」と考え方の落とし穴でした）

**回避策**:
- まず軽量モデルから始める（例: `ollama pull llama3.2:1b` → 3B→7B→32bとステップアップ）
- Q4量化版はパラメータ数の半分以下のVRAMで動作する（q4_K_Mなど）

### ハマリ②：Open WebUIがOllamaに接続できない

初回設定でOpen WebUIがOllamaに接続されないトラブルに見舞われました。特にDocker経由の場合、「localhost」の認識違いでよく発生します。

**回避策**:
```bash
# Docker内でOllamaにアクセスする正しいURL
export OLLAMA_BASE_URL=http://host.docker.internal:11434

# またはOpen WebUI Settings > Connection のURLも確認
```

### ハマリ③：UbuntuでDockerの権限エラー

「permission denied: not an admin」のようなエラーが出ることがあります。

**回避策**:
- 自分のユーザーをdockerグループに追加：`sudo usermod -aG docker $USER`
- ただしこれにはログアウト・再ログインが必要（8月確認済）

### ハマリ④：モデルのファイルサイズが大きすぎる

Qwen2.5の127B版などはDLだけで数GB〜十数GBかかります。またストレージ容量も不足がちに。

**回避策**:
- 初めは3B〜7B程度で試す（500MB未満）
- Hugging FaceからDLする場合は`df -h`で確認してからダウンロード

### ハマリ⑤：Open WebUIの日本語表示が化ける場合

特に日本語フォントが入っていないUbuntu環境で「□□」のように文字化けすることがあります。

**回避策**:
```bash
# Ubuntuに日本語フォントをインストール
sudo apt install fonts-noto-cjk
```

## まとめ：Ollama + Open WebUIの次にやるべきこと

OllamaとOpen WebUIはローカルAIの始め方として最高の選択肢です。次のステップでは：

1. **他のモデルを試す**: `ollama pull`で複数のモデルを試し、自分に合うものを見つける
2. **Obsidian連携**: [記事#3](/drafts/article-03-hermes-agent-ob.md)で外部脳構築の手順を紹介しています
3. **クラウドAIも併用**: 最新のニュースが欲しい時はChatGPT無料版を使い分けます

## FAQ（よくある質問）

### Q1. Ollamaは無料ですか？
はい、インストールと利用は完全無料。ただしDLしたモデルの容量はストレージ容量を消費します。（2026年8月時点）

### Q2. Ubuntu以外でも使えますか？
はい。WindowsやMacでもOllama公式ページからインストーラーDLすれば使えます。ただしLinuxが最もコマンド操作が楽です。

### Q3. ネットがない状態でも使えるのは本当ですか？
はい。一度DLしたモデルはオフラインでも動きます。ただし最初のインストール時だけネットワークが必要です。）
