# 広告・アフィリエイト規約ルール

## PR表記（必須）

### 標準版
```
この記事には広告・アフィリエイトリンクを含む場合があります。
```

### 簡易版
```
※本記事には広告が含まれています。
```

### フッター版（本文が長い場合の併用）
```
※このページのアフィリエイトリンクを通じて紹介された商品からの購入に対して、
筆者は報酬を得る場合があります。
```

## 禁止表現

- 「確実に稼げます」「安心収益」→ △ 検証済みの数値のみ表記可
- 「誰でもできます（結果保証含む）」→ × 
- 金額の上限表現 → ○ 実証済み数値と条件付きで使用可
- リスクの最小化を過大表現 → △ 「失敗した場合、～です」まで

## 価格・キャンペーン確認ルール

1. 料金情報は記事作成時に公式ページから確認
2. キャンペーン期間・条件も必ず公式サイトを確認
3. 出典URLと確認日を含める
4. 数値は記事冒頭の日付付きで記載する

## 対象外ジャンル（初期収益化除外）

- 金融商品・投資信託・仮想通貨
- 医療・健康食品
- 法律サービス
- ゲーム・ギャンブル
