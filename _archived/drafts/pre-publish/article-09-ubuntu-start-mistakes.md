# Ubuntu初心者がつまずく10の点 — ターミナルとのリアルな格闘記

※この記事には広告・アフィリエイトリンクを含む場合があります。

## はじめに：Ubuntuでの最初の失敗は「コマンドをうっかりミスしたこと」でした

私はWindowsで十分生きてこれていると思っていたのに、AIローカル環境構築のために Ubuntu を選びました。正直最初はターミナル（黒い画面）への恐怖と不安がありました。「入力ミス1つでPCが止まるかも」という漠然とした不安です。しかし実際に触ってみると、間違ったとしても「直せばいいだけ」のシンプルさがあることに気づきました。

そんな私のUbuntu生活で本当にやらかした（そして誰しもが一度通る）失敗を10個まとめました。同じミスをしないための教訓として読んでください。

---

## TL;DR（結論）

> Ubuntu初心者がやるべきこと：
> 1. コマンドは直接打たずにコピペする
> 2. パス(ディレクトリ)の大文字小文字を確認する (Ubuntuは区別する！)
> 3. sudoパスワードの入力を忘れないようにしておく
> 4. 失敗したらまず「Ctrl+C」で強制終了を試す、そして`sudo apt update && sudo apt upgrade -y`
> 
> 50歳からのLinux学習において最も重要なのは「焦らないこと」と「間違えても大丈夫と信じる勇気」です。

## Ubuntu初心者につまずく10のポイント — 本当にやりがちな失敗の実例

### つまずき①：コマンドのスペルミス（typo）でコケる
最初は手打ちしようとしてついつい `sudo apt updat` とタイプしてしまいました。すると、「No such file or directory」または「command not found」と表示されます。これを1時間調べていたこともありました。
**回避策**：コピー＆ペーストを使うこと。UbuntuのコミュニティやAIに指示されても、手打ちは絶対NGでした。

### つまずき②：sudoパスワードを「入力してる感」で騙される
Linuxでは管理者権限が必要な時に `sudo` コマンドを使います。しかし！ここで奇妙なことに**パスワードを打っても画面上には何も表示されない**のです（アスタリスクすら出ない）。これは「動いてない？」と心配になりますが、正常です。打ち切ってEnterを押してください。
**回避策**：パスワードを忘れないよう、最初に確認しておきましょう。（Ubuntuの初期設定だと自分のログインパスワードと同じですよ！）

### つまずき③：フォルダ移動時の cd コマンドで迷子になる
`cd /home/ubuntu/Documents/AI-Operations` (パスが長い) と打ち込み、「あれ？どこにいるんだ…？」となることが多々あります。
**回避策**：移動したら必ず `pwd` ( Present Working Directoryの略 ) を実行し、今の場所を確認するように習慣付けました。

### つまずき④：大文字小文字の違いに気づかなかったこと
Windowsはディレクトリを区別しません（Aとaが同じ扱いですがUbuntuでは厳密に異なります!）。なので私のフォルダ名「AI-Operations」を打ち込む際に `ai-operations` と打ってしまったら見つからなくなります。これは相当焦りました。
**回避策**：ls コマンドを実行して、実際にあるフォルダが大文字で書かれているかを確認すること！

### つまずき⑤：パッケージが見つからないと騒ぎ立てる
何かインストールしようとして `apt-get install` したら「E: Unable to locate package ○○」と出ました。
**回避策**：Ubuntuでは最初に `sudo apt update` を実行してパッケージリストを更新する必要があります。（これをしないと最新情報が入らないんです。）私の場合はこれを知らずに1日無駄にしました。

### つまずき⑥：ポート番号の衝突でOllamaが起動しない
Ubuntuは元々何らかのサービスで使用しているポート（例：80番、3000番）を使うと「Port already in use」とエラーが出ます。特にAI環境を作る際はおきやすいミスです。
**回避策**：`sudo netstop -tulnp` を使って今どのポートが使用中か確認してから設定しましょう。

### つまずき⑦：ファイルのパーミッション変更を忘れ、「アクセス拒否」になる
自作のスクリプトファイルを実行しようとしても「Permission denied」と表示され、走らせようとした時に困りました。（Linuxは実行権限が必要なんです、Windowsと違う！）
**回避策**：`chmod +x /path/to/script.sh` で必ず実行権限を与えてください。

### つまずき⑧：pipコマンドがなくてPythonが使えない件
Ubuntuには初期状態だと `pip` が付いていないことがあります。「pip install」と打っても「Command not found」に遭遇します。
**回避策**：まずは `sudo apt install python3-pip` でpipをインストールすること！

### つまずき⑨：SSHアクセスでログインできない
PCの遠隔操作のためにSSHを設定しようとしたら繋がらない…。
**回避策**：`ssh user@IP_ADDRESS` の前に、Ubuntu側でsshdが動いているか確認してパスフレーズの設定も済ませておくこと！

### つまずき⑩：Ctrl+Cを押せずにプロセスが止められない
何か重い実行中（Ollamaのpullコマンドなど）に「止めるのにEnter押せないな」と思ったことがあります。
**回避策**：強制終了は `Ctrl + C` と知ってからは落ち着きます。（ターミナルでのデフォルト操作です。）

## やり方・手順詳細

これらをつまずきの克服のために、私はUbuntuを使い続けるにあたり以下のルールを決めました。

1. **全部コピー＆ペースト（目で見ながらタイピング）**
2. **エラーが出たらAIにコピペして聞く** （私自身も50代でGoogleする前にChatGPTが使えます）
3. **「間違えて大丈夫」を自分への戒めにする** （Linuxは壊しにくいように動いています。）

## FAQ （よくある質問）

### Q1. Ubuntuは本当に無料ですか？
はい！WindowsやmacOSとは異なり、Ubuntuは完全無料で永久に使えます。PCにインストールも無料です！（ただし古いPCには重すぎることもあるので、軽めの軽量版Lubuntuを使うのも手です。）

### Q2. 初心者が一番つまずくのはどこですか？
間違いなく **「sudoパスワードの表示が出ないこと」** です。「入力が止まったか？」と焦りますね。でも平気なので打ち切ってEnter！

### Q3. Windowsと同じ感覚で使えますか？
いいえ、大きく異なります（特にコマンド操作）。しかしGUIアプリも増えているのでマウスでの管理も可能です。（その上でターミナルを使えばさらに便利です。）
