# ChatGPTとCanva 無料版でnote記事が作れるか — 50代が実際にやってみた感想

※この記事には広告・アフィリエイトリンクを含む場合があります。

## はじめに：Canvaの「もっと免費じゃん」という発見

私はこれまで、noteの記事を書くときは文字だけで書いていました。タイトルも装飾なしのMarkdown見出しで固めた、いかにもテキストだけのnoteでした。「これってもしかして読みにくい？」と感じていたのも事実です。

そんな中、**Canvaにはこんなに無料版がある！** という事実を知りました。私が驚いたのは：
- 背景テンプレートが数百種類無料で使える
- イラストや写真も100万以上免费素材
- 日本語フォントも複数用意されている

そして ChatGPT（ChatGPT）の力を借りて、文章の下書きからデザインまで全部フリーでおこなったのが今回の検証です。結果、「見映えの良いnoteの記事が作れる」ことが分かりました。

## 検証：Canva免费版で何ができるのか

### Canva の制限（無料プランの場合）

| カテゴリ | 使えるもの | 使えないもの |
|---------|-----------|------------|
| テンプレート | 数千種以上 | Pro専用テンプレ |
| 写真素材 | 100万種類以上 | Premium画像・Premium要素 |
| フォント | 日本語含め数十フォント | Premiumフォント |
| アイコン | ベクターアイコン多数 | some premium icons |
| PDF出力/ダウンロード | PNG/PNG/JPEG/GIF | transparent背景のPNGがPro限定 |

**重要**: Canvaで「透明な背景付き PNG」を保存するには有料版が必要です。無料版はすべてに白バックグラウンドがつきます。ただnoteの記事では、白バックのイラストも十分使えるので問題ありませんでした。

### ChatGPT と Canvaを組み合わせたワークフロー

```
ChatGPTに下書きを依頼   → 画像・アイディアも ChatGPTに提案してもらう
    ↓
Canvaでカバー画像作成        → テンプレートから選んでタイトル入れ
    ↓
注文中のイラストはCanva         → テナプレのアイコンを使う
    ↓
noteにアップ                → PNGファイルとして貼り付ける
```

このように、**ChatGPTが文章の肉付け、Canvaがビジュアルの補完**をします。両者の力を合わせた方が、単体でやるよりはるかに楽で効果的です。

## 具体的なやり方（手順解説）

### ステップ1：ChatGPTに下書きを依頼する

まずnoteの記事の下書きを ChatGPTに書かせます。私が使ったプロンプト（入力文）は以下の通りです。

```
以下をnote記事の下書きとして書いてください。

テーマ: 「50代からUbuntuでローカルAI環境を作ってみた」
読み手: 50代の初心者、技術用語に慣れていない人向け
構成: はじめに→結論→本文（体験談付き）→FAQ(3〜5問)→まとめ
トーン: 丁寧だが堅苦しくない conversational tone
文字数: 1500〜2000字程度
```

**注意点**: 「どんなフォーマットで出力してほしいか」を指定しないと、チャットの返答がぐちゃります。上の例は私が最もよく使うプロンプトです。

### ステップ2：Canvaでカバー画像を作る

ChatGPTの文章ができたら、Canvaでカバーイメージを作ります。

1. [canva.com](https://www.canva.com/) にアクセス → 無料アカウント登録（Googleアカウントがあれば一瞬）
2. 「記事カバー」や「ブログヘッダー」を検索
3. 気に入ったテンプレートを選ぶ
4. タイトルを自分のものに書き換え

この時、**フォントは日本語対応のものを選べ**ます。例えばM PLUS Rounded 1cやNoto Sans JPなど。50代向けのトーンには少し丸いフォントがおすすめです。

### ステップ3：本文中のイラストもCanvaで準備

noteでは文字だけでなく画像を挿入できます。「見出しごとのイラスト」も Canvaで作れます。

- 「AIをテーマにしたアイコン」を検索して、そのままPNGとしてダウンロード
- 画像サイズを変更 → noteに貼り付ければ完了

### ステップ4：noteにアップする

Canvaで作成したPNGをダウンロード後、noteの投稿画面で「画像を追加」をクリックします。カバー画像と本文中のイラストの両方が貼り付けられます。

## 実際にやってみて分かったこと

### 良い点
1. **見映えが一気に良くなった** — 文字だけと比べて読者が離れにくそう
2. **Canva無料版で十分使えた** — Proプランを買わずともカバー画像くらい作れる
3. **ChatGPTの下書が案外まともだった** — 自分の頭でもっと時間がかかる

### つまずいた点（ハマりポイント①〜③）

#### ハマリ1：ChatGPT の出力が日本語フォントと相性が悪い場合も

ChatGPTの出力された段落をそのままコピペすると、文字幅や改行位置が崩れることがあります。特に半角スペース全角スペースが混在するとnote側で表示がおかしくなりました。**注意: copy-pasteの前に必ず全文を見直すことが必要な** です。

#### ハマリ2：Canvaのフォント制限

無料プランでは使えないフォントもあります。「これは有料版じゃなきゃ使えないんだ」と思ってもう一丁探したことがあります（正直に言います）。

#### ハンまり3：noteにアップロードする際のファイル形式で躓いた

CanvaはPNG, JPEG, PDFなどを出力しますが、noteが対応しているのはPNGとJPEGです。PDFをアップロードしようとするとエラーになりました。これも最初分かりませんでしたね。（後でもう一度確認）

## FAQ（よくある質問）

### Q1. Canvaは無料で本当に免费ですか？
はい、Basic版は永久無料です。有料プランもありますが必須ではありません。

### Q2. ChatGPTの下書きはそのまま使っても大丈夫ですか？
問題ありませんが、自分の言葉で少し直して加筆することが大切です。AIのままだと単調な文章になりますね。(ただし、「嘘や架空の数値をAIが出さないように」確認が必要です。)

### Q3. Canvaで作った画像は商用利用できますか？
Canivaの免费素材もほとんど商用利用可能です。（※一部プレミアム素材を除く）noteに貼るには問題ありません。
