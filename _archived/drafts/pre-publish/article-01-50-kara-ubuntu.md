# 50代からUbuntuでローカルAI環境を作ってみた — 感想・手順・おすすめ

※この記事には広告・アフィリエイトリンクを含む場合があります。

## はじめに：月々のサブスク料を支払うことに疲れた

私はここ数年、ChatGPTのPlusプラン（月額¥2,200前後）を契約していました。便利なのは間違いありません。ただ「使うたびに課金されるような感覚がないのは良いものの、月に1回以上の支払いがあるのが嫌」と思い始めています。

とくに私が使いたい用途は「テキスト生成や要約」「コードの補助」など日常的なものでした。そんなとき、**ローカルAI（自分のPC上にAIを置く）** という選択肢に出会いました。

この記事では、50代・Ubuntu初心者だった私が実際にローカルAI環境を構築するまでの手順と感想、おすすめポイントを体験ベースにまとめます。もし「高いサブスクを支払うのはちょっと……」と思っている方がいたら、ぜひ参考にしてください。

---

## TL;DR（結論）

> Ubuntu上にOllamaとMistral/Llamaなどのローカルモデルを導入することで、毎月の有料サブスクなしでテキスト生成・要約・プログラミング支援が行える。
> 
> 初期費用として ¥150,000〜のPC投資が必要だが、その後は維持費ゼロ。オフラインでも使えるため、プライバシーやセキュリティも確保できる。

## 私がUbuntu + ローカルAIを選んだ理由（筆者の実体験）

### 1. なぜローカル AI を選んだのか？

私は以下の3つの理由で、クラウドではなくローカルを選択しました。

| モチベーション | 具体例 |
|--------------|--------------|
| **月々のコストを抑えたい** | ChatGPT Plus ¥2,200 + Claude Pro ¥4,400 = 月¥6,600も支払っていたのがゼロに！ |
| **オフラインでも使いたい** | ネット回線のない場所でもチャットや要約ができる。 |
| **プライバシー重視** | 自分のデータが外部サーバーに出ない（完全なローカル動作）。 |

### 2. Ubuntu を選んだ理由

- Linux系OSは無料で使える
- サーバー・開発者の間では一番メジャーで、情報が豊富
- AIモデルの公式サポート（OllamaやvLLMなど）がLinux環境向けに最適化されている

#### ハード構成（私のもう一つのPC）

- **マシン**: GMKtec EVO-X2 AI
- **RAM**: 96GB DDR5
- **GPU**: NVIDIA RTX 3090 (VRAM: 24GB)
- **OS**: Ubuntu 24.04 LTS

### 3. 私がハマリポイント（失敗から学んだこと）

私が実際に試して分かった、ローカル AI 環境構築で陥りやすい罠を列記します。

#### ● ハマ①：最初のモデル選びで迷った
最初は「Llama3」を選ぼうとしましたが、VRAMが足りずエラーになりました。**回避策**：メモリ効率の良さそうな **Mistral 7B（4bit QK Quantized）** から初めて、徐々に大きいモデルを移行しました。

#### ● ハマ②: Python依存関係でインストールに失敗
pip installコマンドで「ModuleNotFoundError」「No module named 'numpy'」と表示され、何時間か格闘しました。**回避策**：まず **python3-pip** と python3-venv をsudo aptでインストールしてから venv 環境を作ったら解決！

#### ● ハマ③: Open WebUI で Ollama のモデルが認識されない場合の対処法
Open WebUI が起動していても「Ollama に接続できません」と表示され、ローカル AI モデルが一覧に表示されないことがあります。**回避策**：Open WebUI の設定画面内の API URL を `http://localhost:11434` に設定し直したら解消しました。

## Ubuntu + ローカル AI を構築する手順（50代向け）

以下が私が実際に踏んだ手順です。コマンドは基本、ターミナル（黒い画面）で入力していきましょう。

### ステップ 1：Ubuntu のインストール

まずはパソコンに Ubuntu をインストールします。USBメモリからブートできるイメージファイルを [ubuntu.com/download](https://ubuntu.com/download/desktop) からダウンロードし、Rufusなどのツールを使ってUSBブータブルメディアを作成しましょう。（参考：[Ubuntu Desktop 手順書](https://help.ubuntu.com/)）

```bash
# PCを開けたらターミナルでバージョンを確認する（Ubuntu版かどうかのチェック）
uname -a
```

### ステップ 2：Ollama のインストール

ここから本格的な構成となります。まずは AIモデルをローカルにダウンロード・実行するための Ollama を入れましょう。

```bash
# Ollamaの公式スクリプトでインストール（ワンコマンド！）
curl -fsSL https://ollama.com/install.sh | sh
```

### ステップ 3：AI モデルのダウンロードと起動

```bash
# Mistral 7B というモデルをOllama上にダウンロード
ollama pull mistral

# ダウンロードが完了したら、実際にモデルを使ってみる！
ollama run mistral
```

これだけでローカル AI とチャットできるようになります。

### ステップ 4：Open WebUI を入れる（ChatGPT風のUIで操作する）

ターミナル上で動かすのはハードルが高すぎると感じた場合は、Webブラウザから使えるフロントエンド「Open WebUI」がおすすめです。

```bash
# Docker のインストールが必要なので先に docker を準備
curl -fsSL https://get.docker.com | sh

# Open WebUI の起動（Docker コマンド）
sudo docker run -d --name webui -p 3000:8080 --add-host=host.docker.internal:host-gateway -v ollama:/app/backend/data --restart always ghcr.io/open-webui/open-webui:main

# ブラウザで http://127.0.0.1:3000 を開くと操作画面に！
```

## 実際に使ってみて感じたこと（感想）

| カテゴリ | 良かった点 | 悪かった点 |
|----------|-----------|-----------|
| **コスト** | ¥0/月で何時間でも使えるので嬉しい | ハード代として ¥200,000 〜 の初期投資が必要 |
| **スピード** | モデルをローカルで実行するので応答は速い（1〜3秒程度） | VRAMが足りないモデル（例: Mixtral 8x7B）では60秒以上かかることがありストレスに |
| **機能** | テキスト生成、要約、簡易的な翻訳が可能 | リアルタイムの検索結果や最新情報が取れない（オフライン動作のため） |
| **セキュリティ** | 自分のPCの中だけで完結するので安心 | 電源ONまたはバックグラウンドで常時メモリを消費する（96GBRAM中Ollamaが半分くらい使ってしまっている状態がある） |

### 私が思った「良くなかった点」

- VRAMの制約で、重いローカル AI モデルは動作に時間がかかること
- 最初の設定は少し複雑（初心者にはハードルが上がる）

## まとめ：月々のコストゼロで使えるのは本当に大きいです

UbuntuとOllamaを使うことで私は月に ¥6,600 ものサブスク費をなくすことができました。しかもオフラインで AI が扱えるようになり、プライベートの情報を守りながら活用できるようになりました。

ただし注意すべき点もあります。1つは**最初の環境構築が少し難しいこと**。ターミナルでのインストールに抵抗がある方にはハードルが高いかもしれません。もう一つは**PCのスペック**。VRAM（VRAM4GB以上推奨）のないマシンでは重いモデルを動かすのが大変です。（私の場合 RTX 3090 / VRAM24GB を使っているのでスムーズでした。）

それでも、月々のサブスクなしでAIが使えれば、それはもう大きなメリットだと私は思います。ぜひ一度ローカル AI の世界に飛び込んでみてください。最初はコマンドラインでのインストールにも少し不安があるかもしれません。でも私がそうだったように、1週間のトライ＆エラーさえ乗り越えれば、その後は快適な日常が待っています！

## FAQ（よくある質問）

### Q1.Ubuntuとは何ですか？
Ubuntuは世界中のボランティアが開発している無料OSです。Linuxベースで、企業や開発者にも人気があります。Windowsと違いGUI（ウィンドウの操作画面）もありますがターミナルでの設定も必須になります。

### Q2.ChatGPT Plusと比べてどれほどコストが違うのか？
ChatGPT Plusは月 ¥2,200〜 くらいかかります。ローカル AI は初期投資に ¥150,000 〜 × ¥0/月の維持費なので、3ヶ月で回収できます！（※ただしPCを既に持っている場合は初期投資 ¥0 と考えられます。）

### Q3.本当にオフラインの環境で使えますか？
はい！一度インストールされたモデルは完全にオフラインで動作します。ネットがない場所でチャットや要約が行えるのは、ローカル AI の大きなポイントです。
