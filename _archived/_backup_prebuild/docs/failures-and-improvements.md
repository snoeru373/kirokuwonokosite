# 失敗談・改善記録

## カテゴリー概要

実際に試してみてうまくいったこと、いかなかったことを正直に公開します。

## カテゴリーの目的

1. 「成功体験」だけでなく「失敗体験」も開示して、同じ過ちを繰り返さないために役に立つ情報を提供する
2. CTRが低い記事→タイトル改善 → CTA改善 → リライト まで trackedで記録する
3. 月次・年次レビューの結果を後から振り返れるようにする

## データ構造(追記予定)

| 日付 | カテゴリ | 概要 | 結果 | ステータス |
|------|---------|------|------|-----------|
| 2026-07-?? | CTR改善 | タイトル差し替え | CTR 1.2% → 3.2% | OK |
| 2026-08-?? | CTA改善 | フッターにCTA追加 | Clicks +5 | NG |

## カテゴリーの公開ルールメモ

- 失敗は必ず「何が起きたか」「なぜ起きたか」まで書く
- 「次どうするか」も一緒に記載する
- このカテゴリーは「等身大の実践者」らしくありたい → 誇らない・隠さない姿勢
