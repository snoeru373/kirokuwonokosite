    サイト形式 — 推奨：MkDocs + GitHub Pages¶

    Markdownを書く
  ↓
MkDocsでHTML化
  ↓
GitHubへpush
  ↓
GitHub Pagesで公開

    なぜMkDocsか: - Markdown運用と相性がよい - Obsidianのメモを記事化しやすい - Ubuntuで管理しやすい - GitHub Pagesへ無料公開できる - WordPressの保守・プラグイン・攻撃対策が不要 - Hermes Agentがファイル単位で自動編集しやすい

    noteの役割¶

    noteには収益記事を大量に置くのではなく、次のような記事を置きます。

    • 50代からUbuntuでAI環境を作ってみた話
    • AIに聞きながら環境構築したので、実は全部は覚えていない話
    • でも、それを記録化したら記事になった話
    • 無料でアフィリエイトサイトを作る実験を始めた話

    noteは「人柄」と「実体験」を見せる場所にします。収益導線はnoteからGitHub Pagesの記事へ誘導します。

    媒体設計の優先順位¶

    優先 メディア 費用 役割
    1 GitHub Pages 無料 アフィリエイト記事の母艦
    2 note 無料 体験談・信頼形成・導線
    3 X 無料 記事拡散・反応テスト
    4 Cloudflare Pages 無料枠 GitHub Pagesの代替・高速配信
    5 YouTube Shorts 無料 後から追加する集客導線

    狙う商品ジャンル¶

    有料レビューのために商品を買う必要はありません。すでに使っているもの・無料プランで検証できるもの・読者が無料で始められるものを中心にします。

    ジャンル 紹介するもの 理由
    Ubuntu・ローカルAI Ollama, Open WebUI, Obsidian, Hermes Agent, 無料ツール 実体験がある
    GitHub Pages GitHub, 静的サイト, Markdown運用 すでにGitHub Pages経験あり
    note運用 note記事, 無料テンプレ, AI記事化 既存note再開と接続できる
    無料AI活用 ChatGPT無料枠, Canva無料版, Google系無料ツール 初心者向けに強い
    PC周辺機器 既に持っている機材, SSD, メモリ, ミニPC関連 Amazon・楽天と相性がよい
    学び直し AI本, Ubuntu本, 副業本 50代学び直しテーマと相性がよい

    収益化ASPの優先順位¶

    優先 ASP 費用 使いどころ
    1 A8.net 無料 サーバー, 学習, SaaS, ツール系
    2 もしもアフィリエイト 無料 Amazon・楽天リンク, ブログ運用
    3 楽天アフィリエイト 無料 ガジェット, 書籍, PC用品
    4 Amazonアソシエイト 審査あり 10記事以上作ってから
    5 AIツール公式 無料登録 後から追加

    各ASPの詳細:

    • A8.net: 広告主数27,000社以上、登録サイト360万サイト以上。無料ブログでも登録可能。
    • もしもアフィリエイト: W報酬(通常+12%ボーナス)、かんたんリンク機能付き。
    • 楽天アフィリエイト: 楽天会員なら面倒な登録なしでリンク取得可能。SNSでの紹介にも対応。
    • Amazonアソシエイト: 申請後180日以内に3件の適格販売が必要。目安として10投稿が示されているため、最初に主力にせず記事10本揃えてから申請が安全。

    ポイント¶

    1. 初期は高単価案件より無料導入記事で信頼を作るほうが重要。広告費を使えないため、検索流入とSNS反応が育つまで時間がかかる。
    2. いきなり高単価案件だけを狙うより、無料記事で信頼を作り、物販・書籍・ツール紹介で小さく成果を拾う形が安定する。
    3. noteからは「体験談」→ GitHub Pagesの「本記事」への導線に徹する。
