    毎朝米国株を自動売買してSlackに会社名つきで報告するAIエージェント — 要約¶

    出典¶

    • Twitter: @SuguruKun_ai
    • クリップ日時: 2026-07-15

    要約（全文）¶

    週末に Claude Code に「米国株の自動売買 Bot を組んで」と頼み、作って動かし始めて 1ヶ月 の記録。VPS常駐・平日朝6時（日本時間）に勝手に動く。投資助言ではなく特定銘柄非推奨。少額で実弾テスト。3戦略を並走させAI審査付きの2段ゲート方式で暴走防止。

    全体骨格：4つの戦略をVPSで並走させる¶

    # 戦略名 概要
    1 配当貴族（守り） 25年以上連続増配の銘柄に集中的に
    2 モメンタム（順張り） 過去12ヶ月で上がってる株価に乗る
    3 リバーサル（逆張り） 短期で売られすぎた銘柄に逆張りに
    4 低ボラ（安定） 値動きが穏やかな銘柄に寄せる

    証券会社は Alpaca API で売買。Claude Code が Python一式を組む。

    5つのポイント¶

    1. まず4戦略を一気に骨格化 → Paperで先に回す¶

    Claude Code がPaper→VPS常駐まで一気にやってくれたのが驚き - いきなり実弾に行かず、まずPaper（仮想売買）で回す設計にしてくれた - VPSにsystemdのtimerを仕込み、平日朝6時に自動実行するところまで一気通貫

    2. ルールが出したシグナルをAIにもう一段「審査」させると暴走が止まる¶

    [戦略ルール（シグアウト）] → [Claude AI審査ゲート] → [発注（Alpaca API）]
    • 「上がってるから買い」としか言わないルールに、"今の相場観だとこれ大丈夫？" という審査を1枚かませる
    • 確信が低いものは却下。レポートに「採用◯件/却下◯件」も入るので「なんで買ってない？」も後で追える

    3. Slackに毎朝のポートフォリオ状況とグラフを送らせる（一番大事）¶

    毎朝Slackに投げる4つの内容： 1. 現金・評価額・含み損益 2. 今日出たシグナルとその理由 3. 30日の成績をS&P500と比較した1行 4. 資産推移＋S&P500折れ線グラフ（matplotlib生成、画像添付）

    テキストだけだと読まらない。画像を毎日1枚貼ると効いた。「スマホでパッと分かる」状態は重要。

    4. 詰まったポイント：「T」「VZ」という記号だけの表示は読めない → 会社名に直し¶

    最初、レポートにティッカー（"T""VZ""MU"）だけで出ていたが、「会社の名前と売買理由も出して」と指示したら： -Claude Code が対応表を作成→ クローズアップした。会社名と理由が表示で読みやすさが段違いに改善。しかも既存の227件テストを壊さずに自動修正

    5. 「AI・半導体に寄せて」 → チャット1行でやれた（極めつけ）¶

    ポートフォリオには「30%までのセクター集中アップ」というブレーキがあるため、AIに任せすぎても既存の守り株を全部売るわけではない。しかし Claude Code が： - 今の構成を調べて"AI寄せにするにはこれだけ足りないよ"と返してきた - "実際に出す注文の一覧" を先に開示した（勝手に発注しない） - OKを出したら AI・半導体のバスケット新設→配分変更→口座入れ替えまで通してくれた

    AIに寄せたい → 一言で実際のポートフォリオ変更に至る距離の近さが Claude Code の本番

    最小限で真似するなら（3ステップ）¶

    1. まずはPaper（仮想売買）口座で回す。シグナル生成→発注の流れだけ動かしてみる
    2. 戦略は1つでも十分。4つ並べる前に単純骨格をClaude Codeに作らせて、ログ眺める
    3. レポートを整える → 「何を持ってて、なぜ動いたか」が読めてから少額実弾

    事故りたくないならこの順序を徹底すること

    まとめ：一番価値を感じたポイント¶

    一番の価値が利益じゃなくて、「頭の中の思いつきがその日のうちに動くシステムになる」体验の方だった。証券API・VPS常駐→AI審査→レポート生成→自然言語での方針変更まで、週末の片手間でここまで来ている。個人でここまでできることが本当にすごい。

    Brain3 Vaultでの応用可能性¶

    米国株Botの構成 Brain3 Vaultでの代替案
    VPS + systemd timer hermes cron（daily実行）+ Watchers監視
    Alpaca APIで売買 Himlaya CLI or Gmail API for行政資料自動取得
    Slack毎朝レポート Telegram or Discord通知
    ルールシグナル → AI審査 Pythonスクリプト → Hermes Agent のレビュー処理
    matplotlib 画像添付 Open WebUIで可視化 or MkDocs記事として保存
