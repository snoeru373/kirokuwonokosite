    読者の悩み¶

    1. WordPressはサーバー代もドメイン代もかかる
    2. 有料テーマも高い
    3. でも無料ブログって信頼されなさそうで不安

    ターゲットユーザー¶

    ユーザー層 こんな悩みを持っている
    副業を始めたい50代 まずお金かけたくない
    ブログ初心者 WordPressのインストールからわからない
    フリーランス志望者 ポートフォリオサイトを無料で作りたい

    実体験¶

    背景と動機¶

    • WordPressを一度触ったが、サーバー設定に挫折した
    • MkDocs + GitHub Pages の組み合わせを知り、「これはいける」と思った
    • コスト計算: サーバー¥0 + ドメイン¥1,500/年 = 完全に無料に近い状態

    やってみた結果¶

    • 良い点: コストがほぼゼロ、Git管理でバージョン追跡可能
    • 不満だった点: プラグインがないので機能拡張に限界がある

    ハマりポイント①〜③¶

    • ハマリ1: Gitのコミット手順で初めてつまづいた
    • ハミリ2: Markdown記法ではまってしまった
    • ハミリ3: GitHub Pagesの公開設定が見付からない

    やり方・手順の詳細¶

    ステップ1 — 必要なツールのリスト（全部無料）¶

    ツール 価格 URL
    MkDocs 無料 mkdocs.org
    MkDocs Material 無料 github.com/grantjen
    GitHub Pages 無料 pages.github.com
    Obsidian 無料（デスクトップ） obsidian.md

    ステップ2 — MkDocsサイトの初期構築¶

    pip install mkdocs mkdocs-material
mkdocs new . && cd .

    Q1. WordPressと何が違うのですか？¶

    → A1: WordPressはPHP+MySQLが必要ですが、MkDocsはMarkdownのみ。サーバー不要です。
