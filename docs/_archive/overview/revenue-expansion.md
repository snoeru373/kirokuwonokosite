# 収益展開：無料メディアで月1万 → 月5万 → 月10万へのルート {{< internal-link revenue-expansion-overview >}}

## 1. 「母艦 + SNS」の二軸構造
| 媒体 | 役割 | コンバージョン |
|------|-----|---------------|
| GitHub Pages / MkDocs | 技術検証・比較・SEO流入 | ASPリンク |
| note | 信頼形成・フォロワー増 | 有料マガジン / 母艦誘導 |
| X(Twitter) | 拡散・バズ狙い | SNS広告経由ASP |

## 2. 最初の1万円を稼ぐまで
- まず母艦で「ローカルAIセットアップ」の記事を書く (Google Geminiやchatgpt.comなど。参考：{{< internal-link ollama-openwebui >}} )
- noteで体験記を投稿し、フォロワーを獲得
- 「有料マガジン $2.99」を月50人に買ってもらう = $150/月 ≈ ¥22,000

## 3。ASP登録後の収益計算例（Bbit）
記事×10本 × クリック率(5%) × Bbit手数料(50%) × 月額$10 = ¥75,000/月！
つまり、**母艦10本 + noteフォロワー100人** で、月に¥2〜3万は可能。
