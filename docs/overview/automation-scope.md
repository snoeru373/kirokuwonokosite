# 自動化の範囲：AIに任せるべきこと vs 手動すべきこと

## 1. AIで自動化できるもの （80%）
- **下書き生成**：ChatGPT → h1-h2見出し + body構成 {{< internal-link article-06-chatgpt-canva-note >}}
- **画像作成**：Canva（アイキャッチ画像）→ 5分で完了
- **SNS投稿自動化**：Hermes Agent + cronによる定期投稿

## 2. AIでは「無理」な部分 (20%：この部分が収益を左右する)
- **信頼性のある体験記の執筆**: 「自分しか書けない失敗例・体験記」は必須。これはAIでは書けません。
- **コメント返信**：読者からの質問には必ず手動で返信しましょう

## 3. 最適な自動化ロードマップ
| ステップ | AIに任せる部分 | 人間の手が必要な部分 |
|---------|--------------|-------------------|
| 記事1〜5 | Chatgpt下書き＋自分で編集 | 感想・体験の追加 |
| 記事6〜10 | Canvaアイキャッチ自動化 | チェック |
| 画像自動投稿 | Hermes agent + note連携 | 月1回確認 |

## まとめ
まずは「ChatGPT × Canva」で週5本継続しましょう！{{< internal-link thirty-day-roadmap-overview >}}
