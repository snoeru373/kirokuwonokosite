# 無料版の媒体設計：月数万円を目指すために必要なプラットフォーム {{< internal-link media-design-overview >}}

## 1. なぜ無料で始めるのか？
- **失敗リスクゼロ**：サーバー費用やドメイン代がかからないので、試した分が資産になる
- **素早いテストが可能**：noteは即公開できる
- **母艦としての信頼度**：GitHub Pages上の技術ブログが安心感を生む

## 2. 三軸の役割分担

### GitHub Pages / MkDocs（母艦）
「技術的な検証記事」や、比較まとめ系の記事を配置。SEO流入の主戦場です。

### note（母艦SNS）
- 体験記・失敗例を発信
- フォロワーとの信頼関係形成に最適
- 「有料マガジン」で直接収益化も可能

### X(Twitter)（拡散エンジン）
- Google GeminiやChatGPTの体験したツール紹介をツイート
- noteの記事への誘導

## 3. 検索流入とSNS経由のバランス
初心者の場合、Googleインデックスがされるまで1ヶ月〜3ヶ月かかります。その間、noteフォロワーからの「SNSでの拡散」が命綱です！

## まとめ
この媒体設計で月数万円の収入を得るためには、**まず30日間毎日1記事続けること** {{< internal-link thirty-day-roadmap-overview >}} が最も重要になります。
