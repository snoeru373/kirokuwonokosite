# WordPressを使わずに無料のWebサイトを作る方法 {{< internal-link article-05-no-wordpress >}}

## 1. WordPressの何が問題なのか？
WordPressは有名なCMS（コンテンツ管理システム）ですが、以下の懸念点があります：

- **サーバー費用がかかる**：月数百〜数千円
- **プラグインやテーマの管理に時間がかかる**
- **セキュリティアップデート必須（放置するとハッキングされる）**
- **日本語ローカライズが不完全**

50代の方で「有料メディアを作るのは不安」という方には、MkDocsのような静的サイトビルダーが最適です！

## 2. MkDocsのメリット一覧
| 項目 | WordPress | MkDocs+Material |
|------|-----------|-----------------|
| サーバー費用 | 月額制（$3〜） | 完全無料 |
| デザイン | テーマ選びが必要 | Materialテーマが最初から完成 |
| SEO対策 | Yoast必須 | sitemaps.xml自動生成 |
| ハッキングリスク | × | ◎ (静的サイト=攻撃対象にならない) |
| 記事作成 | HTMLエディタ | Markdown一択（簡単！） |

## 3. 実際にMkDocsで書いた方の感覚
「WordPressに比べて5倍くらい早く書ける」が私の感想です。Markdownは「見出しには#、太字には**」というシンプルな記法だけなので、難しい作業は一切ありません。その上、[三十日のロードマップ](../thirty-day-roadmap-overview.md)の第2週で実際に書いて公開体験ができます!
