# Affiliate Learning Memory

## 基本方針

無料運用を前提とする。  
有料サーバー、有料ドメイン、有料AI API、有料SEOツールは使わない。

## 主力媒体

- GitHub Pages
- note
- X
- Cloudflare Pagesは代替候補

## 主力テーマ

- Ubuntu
- ローカルAI
- Ollama
- Open WebUI
- Hermes Agent
- Obsidian
- GitHub Pages
- note再開
- AI副業
- 50代の学び直し

## 勝ち記事の条件

- 実体験がある
- 失敗談がある
- スクリーンショットがある
- 無料で試せる
- 手順が具体的
- おすすめしない人も書いている
- 広告リンクが自然

## 禁止表現

- 必ず稼げる
- 誰でも月〇万円
- 完全放置
- 絶対おすすめ
- これ一択
- 公式より安いと断定
- 根拠のないランキング

## 改善ルール

- 表示回数があるのにCTRが低い記事を優先してタイトル改善する。
- CTRがあるのに成果がない記事は商品導線を見直す。
- 成果がある記事は関連記事を追加する。
