## 広告・アフィリエイトリンクについて

当サイトでは、記事内に広告・アフィリエイトリンクを含む場合があります。

リンク経由で商品やサービスを購入・申し込みいただいた場合、運営者に報酬が発生することがあります。

ただし、読者の方が支払う料金が通常より高くなることは基本的にありません。

広告・アフィリエイトリンクを含む記事では、記事冒頭またはリンク付近に、広告・アフィリエイトリンクを含むことが分かる表示を行うよう努めます。

例：

```text
※この記事には広告・アフィリエイトリンクを含む場合があります。
```

または、

```text
※この記事には広告・アフィリエイトリンクを含みます。リンク経由で商品やサービスを購入・申し込みいただいた場合、運営者に報酬が発生することがあります。
```

## 商品・サービス紹介の方針

当サイトでは、商品やサービスを紹介する場合、以下の方針を大切にします。

```text
・実際に使ったもの、調べたもの、記事テーマと関係があるものを中心に紹介する
・報酬単価だけを理由に紹介しない
・読者の悩み解決につながるかを重視する
・メリットだけでなく、注意点や向いていない人も書く
・公式情報を確認する
・誇大表現を避ける
・収益や成果を保証する表現を使わない
```

紹介している商品やサービスが、すべての人に最適であるとは限りません。

利用する場合は、ご自身の目的、環境、予算、必要性に合わせて判断してください。
