# ヒーローセクション黄金プロンプト

## 概要

Open CoDesign / Open Design で高成約率のヒーローセクションを生成するための汎用テンプレート。コピペで即使用可能。

## プロンプト

```text
あなたはUI/UXデザイナー兼コピーライターです。
以下の条件を満たす「ヒーローセクション」を設計してください。

# 1. ターゲット（具体化必須）
・年齢：27〜29歳女性
・職業：会社員（都内勤務）
・年収：350〜500万円
・性格：慎重・効率重視・SNSリテラシー高め
・行動：スマホ中心、比較検討してから購入
・価値観：「無駄がない」「シンプル」「信頼性」

# 2. 悩み（1つに絞る）
・例：「〇〇に時間がかかりすぎて疲れている」「〇〇が難しくて継続できない」「〇〇の情報が多すぎて選べない」
※必ず"日常シーン"として描写する

# 3. ベネフィット（機能ではなく結果）
・NG: 機能説明（AI搭載、簡単操作）
・OK: 変化（〇〇が10分で終わる、迷わなくなる、ストレスが減る）

# 4. ヒーロー構成（必須）
① キャッチコピー（20文字前後・感情直撃）
② サブコピー（具体的ベネフィット）
③ 信頼補強（実績・数字・安心材料）
④ CTA（1つに絞る）
⑤ ビジュアル指示（写真 or イラストの具体内容）

# 5. コピー制約
・抽象語禁止（便利・簡単・すごい）
・必ず数値 or 比較を入れる
・1文は最大40文字
・「自分ごと化」優先

# 6. デザイン仕様（Notion風）
以下を厳守：
・背景：ホワイト（#FFFFFF）
・アクセント：グレー系（#F7F7F5 / #EDEDED）
・文字：黒（#1F1F1F）
・フォント：サンセリフ（Inter / Noto Sans）
・余白：広め（左右32px以上）
・影：なし or 極小
・角丸：6〜8px
・装飾：最小限（アイコンは単色）

# 7. レイアウト
・PC：左テキスト / 右ビジュアル
・SP：縦積み（テキスト→CTA→画像）
・CTAはファーストビュー内に必ず配置

# 8. 出力形式
【キャッチコピー】
【サブコピー】
【信頼補強】
【CTA】
【ビジュアル指示】
【レイアウト構造（テキスト）】

# 9. NG
・マーケっぽい誇張
・意味のない英語
・情報過多
```
