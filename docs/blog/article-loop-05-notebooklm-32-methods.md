## 要約（全文）

NotebookLMを「資料の要約ツール」として使っているなら、**その実力の半分も引き出せていません**。9割の人が「要約して」→コピー→終了で止まっているが、それは高性能なエンジンを駐車場であいidleさせているようなもの。32の使い方を全部解説。

---

## NotebookLMの核心：Claude Codeとの違い

| 特徴 | Claude Code / Codex | NotebookLM |
|---|---|---|
| **得意** | ゼロから生み出す（コード、アプリ） | 渡された素材を極限まで活かす |
| **弱点** | 学習データにない情報は「存在しない」 | 一度入れた素材は永久に使える |

- NotebookLM = 「渡された素材を武器に変える料理人」
- Claude Code = 「無から有を作る職人」

**32番目：掛け合わせが重要**。Claude CodeとNotebookLMをMCPでつなぐことで、"生成前に必ず裏取りしに行く"信頼性の高いパイプラインになる。

## NotebookLMとClaude Code/MCPの掛け合わせ

> 「お金の発信をしてた時、AI任せで利回り計算を出したら手計算と全然違う数字が返ってきた。出す直前に気づいて助かった。もし出していたらフォロアーに誤った数値を届けていた」

- **公式ソースを1本入れる手間：一度きり** → 次の100本すべての信頼を底上げ
- **「一次情報の複利」**：使えば使うほど裏取りコストがゼロに近づく

```
ChatGPT Gemini → 生成（ウソつきする） ←→ NotebookLM（素材のみ回答） + Claude Code/Codex（MCPで連携）
       ↑                           ↓
   ハルシネーション                  引用元保証
```

---

## まとめ：3つのやることだけ

1. 引用元リンクで裏を取る（第1-2章）
2. 資料を音声・スライド・図解に自動変換する（第3-5章）
3. Code系と掛け合わせてウソを封じる（第6章）

AIの賢さは性能ではなく**何を食べさせるか**で決まる。
