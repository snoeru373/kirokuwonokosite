## 要約（全文）

月額課金を脱却するために **Claude Designを「タダ同然」で使う方法として、2つのOpenなAIデザインツール**を紹介。

| ツール名 | 概要 |
|---|---|
| Claude Design | Claude CodeのUI/デザイン用機能 → HTML/CSS/JSでプロトタイプ構築 |
| OpenDesign | AIによる画像生成・UIデザイン支援（オープンソース） |
| CoDesign | UI/UXのプロトタイピングに特化したAIツール（オープンアクセス） |

この3つを組み合わせることで、月額数千円→数百円のコストで高品質なUIデザインができる。

## 具体的な使い方

### Claude Code（デザイン編）

```
「このPDFをUIプロトタイプに変換して」
→ HTML/CSSで出力
→ localhost でプレビュー確認
→ ブランディングカラーを指定して再度生成
```

- **Pros**: プロットが速い・カスタマイズ性が高い
- **Cons**: CSSの知識が必要・ブラウザ対応確認の手間がある

### OpenDesign

```
「この概念図のプロトタイプ画像を作成して」
→ AIが直接スクリーンショットを生成
```

- **Pros**: イメージが即座に見られる・アイデアのブラッシュアップに便利
- **Cons**: 詳細なカスタマイズにはClaude Designと併用必要

### CoDesign連携

- プロトタイプ → UIコンポーネント（ボタン、ナビバー、カラムなど）
- Figma/Adobeへのエクスポートにも対応
