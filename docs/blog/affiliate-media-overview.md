# 無料版のメディア戦略・収益化総合指南

### サイト名案

**案1:** 50代からのローカルAI実践ノート

または、

**案2:** Ubuntu × AI 自動化ラボ

### サイトのカテゴリ

1. UbuntuでAI環境を作る
2. Ollama・Open WebUIの使い方
3. Hermes AgentとObsidian運用
4. GitHub Pagesで無料サイト運営
5. noteとAI副業の始め方
6. 無料ツール比較
7. 失敗談・改善記録

### サイト形式 — 推奨：MkDocs + GitHub Pages

```
Markdownを書く
  ↓
MkDocsでHTML化
  ↓
GitHubへpush
  ↓
GitHub Pagesで公開
```

**なぜMkDocsか:**
- Markdown運用と相性がよい
- Obsidianのメモを記事化しやすい
- Ubuntuで管理しやすい
- GitHub Pagesへ無料公開できる
- WordPressの保守・プラグイン・攻撃対策が不要
- Hermes Agentがファイル単位で自動編集しやすい

###noteの役割

noteには収益記事を大量に置くのではなく、次のような記事を置きます。

- 50代からUbuntuでAI環境を作ってみた話
- AIに聞きながら環境構築したので、実は全部は覚えていない話
- でも、それを記録化したら記事になった話
- 無料でアフィリエイトサイトを作る実験を始めた話

noteは「人柄」と「実体験」を見せる場所にします。収益導線はnoteからGitHub Pagesの記事へ誘導します。

## 収益化ASPの優先順位

| 優先 | ASP | 費用 | 使いどころ |
|------|-----|------|------------|
| 1 | A8.net | 無料 | サーバー, 学習, SaaS, ツール系 |
| 2 | もしもアフィリエイト | 無料 | Amazon・楽天リンク, ブログ運用 |
| 3 | 楽天アフィリエイト | 無料 | ガジェット, 書籍, PC用品 |
| 4 | Amazonアソシエイト | 審査あり | 10記事以上作ってから |
| 5 | AIツール公式 | 無料登録 | 後から追加 |

各ASPの詳細:

- **A8.net:** 広告主数27,000社以上、登録サイト360万サイト以上。無料ブログでも登録可能。
- **もしもアフィリエイト:** W報酬(通常+12%ボーナス)、かんたんリンク機能付き。
- **楽天アフィリエイト:** 楽天会員なら面倒な登録なしでリンク取得可能。SNSでの紹介にも対応。
- **Amazonアソシエイト:** 申請後180日以内に3件の適格販売が必要。目安として10投稿が示されているため、最初に主力にせず記事10本揃えてから申請が安全。

## ポイント

1. **初期は高単価案件より無料導入記事で信頼を作る**ほうが重要。広告費を使えないため、検索流入とSNS反応が育つまで時間がかかる。
2. いきなり高単価案件だけを狙うより、無料記事で信頼を作り、物販・書籍・ツール紹介で小さく成果を拾う形が安定する。
3. noteからは「体験談」→ GitHub Pagesの「本記事」への導線に徹する。
