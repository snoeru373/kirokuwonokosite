## 実体験

### 背景と動機
- WordPressを一度触ったが、サーバー設定に挫折した
- MkDocs + GitHub Pages の組み合わせを知り、「これはいける」と思った
- コスト計算: サーバー¥0 + ドメイン¥1,500/年 = 完全に無料に近い状態

### やってみた結果
- 良い点: コストがほぼゼロ、Git管理でバージョン追跡可能
- 不満だった点: プラグインがないので機能拡張に限界がある

### ハマりポイント①〜③
- ハマリ1: Gitのコミット手順で初めてつまづいた
- ハミリ2: Markdown記法ではまってしまった
- ハミリ3: GitHub Pagesの公開設定が見付からない
