# WordPressを使わず無料で副業サイトを作る方法｜GitHub Pages・note・AIで始める実践メモ

※この記事には広告・アフィリエイトリンクを含む場合があります。

## はじめに

副業サイトを作ろうとすると、多くの場合、最初にWordPressをすすめられます。

たしかに、WordPressは本格的なブログやアフィリエイトサイトを作るには便利です。

記事管理、デザイン変更、広告配置、プラグイン、アクセス解析など、ブログ運営に必要な機能をそろえやすいからです。

しかし、最初からWordPressを使うと、次のような費用や管理が必要になります。

* レンタルサーバー代
* 独自ドメイン代
* 有料テーマ代
* WordPress本体の更新
* プラグイン管理
* セキュリティ対策
* バックアップ設定
* 表示速度の調整

副業を始める前から固定費がかかると、心理的な負担も大きくなります。

そこで私は、まずはWordPressを使わず、無料で小さく副業サイトを作る方法を考えました。

この記事では、GitHub Pages、note、X、Obsidian、AIを組み合わせて、無料で副業サイトを作る方法をまとめます。

---

## 結論：最初はWordPressなしで十分始められる

結論から言うと、最初の副業サイトはWordPressなしでも始められます。

特に、次のような目的なら無料構成で十分です。

* 記事を書いて公開する
* 自分の体験を発信する
* アフィリエイト導線を試す
* noteと連携する
* Xで反応を見る
* Search Consoleで検索状況を確認する
* AIで記事下書きや改善案を作る
* 収益化できるテーマか検証する

最初から本格的なサイトを作るより、まずは無料で小さく試すことが大切です。

おすすめの構成は次のとおりです。

```text id="6q8fei"
Obsidian
↓
AIで記事下書き
↓
GitHub Pagesで無料公開
↓
noteで体験談を書く
↓
Xで記事を紹介する
↓
Search Consoleで反応を見る
↓
ASPで収益導線を作る
```

この流れなら、有料サーバーなし、独自ドメインなしでも始められます。

## WordPressを使わない理由

WordPressを否定するつもりはありません。

むしろ、本格的に収益化するなら、いずれWordPressを検討する価値はあります。

ただし、初期段階では次の理由から、WordPressなしで始める方が現実的です。

### 1. 固定費を抑えられる

副業サイトは、最初から収益が出るとは限りません。

記事を書き、公開し、検索に表示され、読者に読まれ、広告がクリックされ、成果が発生するまでには時間がかかります。

その間も、レンタルサーバー代やドメイン代は発生します。

無料で始めれば、収益が出る前の固定費を抑えられます。

### 2. 記事作成に集中できる

最初からWordPressを使うと、テーマ選び、プラグイン設定、デザイン調整、セキュリティ設定などに時間を使いがちです。

しかし、本当に大切なのは、読者に役立つ記事を書くことです。

無料構成なら、余計な設定に時間を使いすぎず、記事作成に集中できます。

### 3. AIとMarkdownの相性がよい

AIに記事下書きを作らせる場合、Markdown形式はとても扱いやすいです。

Obsidian、GitHub Pages、Git、Hermes Agentなどとも相性がよく、ファイル単位で整理できます。

WordPressの管理画面に直接入れるより、まずMarkdownで下書きを管理する方が、AIとの連携もしやすいです。

### 4. やめるときの損失が少ない

副業サイトは、始めてみないと続けられるか分かりません。

無料構成なら、うまくいかなかった場合でも金銭的な損失は小さく済みます。

逆に、反応が出たら、あとからWordPressや独自ドメインへ移行すればよいです。

## 無料副業サイトの全体構成

WordPressを使わずに副業サイトを作るなら、次のような構成にします。

```text id="3uxzzi"
無料副業サイト構成

1. GitHub Pages
   記事・比較ページ・プロフィールを公開する母艦

2. note
   体験談、人柄、読み物、再開ストーリーを書く場所

3. X
   記事の拡散、反応確認、短文発信

4. Obsidian
   記事ネタ、作業メモ、AIとの会話を保存する場所

5. AI
   記事構成、下書き、FAQ、改善案を作る補助

6. Search Console
   検索表示回数、クリック数、CTR、掲載順位を確認する

7. ASP
   A8.net、もしもアフィリエイト、楽天アフィリエイトなどで収益化する
```

それぞれの役割を分けることで、無料でも副業サイトらしい運用ができます。

---

## GitHub Pagesの役割

GitHub Pagesは、副業サイトの母艦として使います。

ここには、検索で読まれやすい記事や、後から何度も見てもらいたい記事を置きます。

たとえば、次のような記事です。

* GitHub Pagesで無料アフィリエイトサイトを作る方法
* AI副業を始めるために必要なPC・サーバー・ツール
* 無料で始めるアフィリエイトASP比較
* OllamaとOpen WebUIでできること・できないこと
* Hermes AgentでObsidianを外部脳にする方法
* AI記事作成でやってはいけないこと

GitHub Pagesは静的サイトなので、WordPressのような管理画面はありません。

しかし、Markdownで記事を書き、GitHubに反映すれば無料で公開できます。

副業サイトの初期段階では、これで十分です。

---

## noteの役割

noteは、検索記事というより、体験談や人柄を伝える場所として使います。

GitHub Pagesには、手順記事、比較記事、まとめ記事を置きます。

一方で、noteには次のような記事を置きます。

* 50代からAI副業を始めようと思った理由
* AIに聞きながらUbuntu環境を作った話
* 作業手順を覚えていないから記録することにした話
* WordPressを使わず無料で副業サイトを作る実験を始めた話
* AIに助けられながら学び直す記録

noteは、読者との距離を縮める場所です。

GitHub Pagesが「情報を整理する場所」なら、noteは「背景や思いを伝える場所」と考えます。

note記事の末尾から、GitHub Pagesの詳しい手順記事へ誘導します。

---

## Xの役割

Xは、記事の反応を見る場所として使います。

最初からフォロワーを大きく増やそうとする必要はありません。

まずは、自分の記事テーマに対して、どんな言葉に反応があるかを確認します。

たとえば、次のような投稿です。

```text id="ui5twg"
WordPressを使わずに、副業サイトを無料で作る実験を始めました。

使うもの：
・GitHub Pages
・Obsidian
・Markdown
・AI下書き
・note
・Search Console
・ASP

最初から固定費をかけず、記事を書いて反応を見ながら改善します。
```

Xでは、記事の要点を短く投稿します。

反応がある投稿は、記事のタイトルや見出し改善にも使えます。

---

## Obsidianの役割

Obsidianは、記事ネタや作業記録をためる場所です。

副業サイトを続けるには、記事ネタを失わないことが重要です。

AIに聞いたこと、Ubuntuでつまずいたこと、GitHub Pagesで設定したこと、ASP登録で迷ったこと。

これらはすべて記事になります。

Obsidianには、次のようなメモを残します。

* 記事ネタ
* 作業メモ
* エラー対応
* AIとの会話
* ASP登録メモ
* 商品候補
* 公開前チェックリスト
* 週次改善メモ
* 成果が出た記事の特徴
* 失敗した記事の反省

Obsidianにメモをためておくと、あとでAIやHermes Agentに記事化を頼みやすくなります。

---

## AIの役割

AIは、副業サイト運用の補助役として使います。

たとえば、次の作業に向いています。

* 記事タイトル案を出す
* 記事構成を作る
* Markdown下書きを作る
* FAQを作る
* 比較表を作る
* 誤字脱字を確認する
* 内部リンク候補を出す
* 広告表記漏れを確認する
* 誇大表現を検出する
* 週次改善案を出す

ただし、AIにすべて任せるのは危険です。

特に、アフィリエイトでは次の確認が必要です。

* 広告であることを表示しているか
* 商品情報が最新か
* 公式情報と矛盾していないか
* 価格や条件を断定していないか
* 「必ず稼げる」などの誇大表現がないか
* ASP規約に違反していないか

AIは下書きと整理に使い、公開前の最終確認は人間が行います。

---

## Search Consoleの役割

記事を書いて公開したら、次は反応を確認します。

無料で使える重要なツールがSearch Consoleです。

Search Consoleでは、主に次のような情報を確認します。

* Google検索に表示された回数
* クリックされた回数
* CTR
* 平均掲載順位
* 検索クエリ
* インデックス状況
* ページの問題

副業サイトでは、記事を書いて終わりではありません。

反応を見て改善することが大切です。

たとえば、表示回数があるのにクリックされていない記事は、タイトルや説明文を改善します。

クリックされているのに成果につながらない記事は、商品導線やCTAを見直します。

---

## ASPの役割

副業サイトを収益化するには、ASPを使います。

初期候補は次の3つです。

| ASP        | 向いているもの          |
| ---------- | ---------------- |
| 楽天アフィリエイト  | 書籍、PC用品、日用品      |
| もしもアフィリエイト | Amazon・楽天系の商品リンク |
| A8.net     | サーバー、学習サービス、ツール系 |

A8.netは、サイト・ブログ・SNSなどのメディアに広告を掲載し、訪問者が広告経由で購入やサービス利用をすると報酬が発生する仕組みを説明しており、無料登録も案内しています。もしもアフィリエイトや楽天アフィリエイトも、無料運用の初期候補として検討しやすいASPです。

最初は高単価案件を狙いすぎず、自分の記事と自然につながるものを紹介します。

たとえば、UbuntuやローカルAIの記事なら、次のようなものです。

* USBメモリ
* 外付けSSD
* AI入門書
* Linux入門書
* キーボード
* モニター
* 作業環境用品

WordPressやサーバーの記事を書く段階になったら、A8.netでレンタルサーバーや学習サービスを探します。

## トップページに書くこと

トップページには、サイトの目的を短く書きます。

例文です。

```text id="g4zpn0"
このサイトでは、50代からUbuntu、ローカルAI、Obsidian、Hermes Agent、GitHub Pagesを使って、無料でAI活用と副業サイト運営に挑戦する実践記録をまとめています。
```

トップページに入れる要素は次です。

* サイトの説明
* 誰に向けたサイトか
* 主なカテゴリー
* おすすめ記事
* 最新記事
* プロフィールへのリンク
* 広告表記ページへのリンク
* noteやXへのリンク

最初は簡単で構いません。

記事が増えてから整えれば十分です。

## プロフィールページに書くこと

プロフィールページは、信頼性を高めるために重要です。

ただし、本名や勤務先など、公開したくない情報を書く必要はありません。

書く内容は次のようなもので十分です。

* 表示名
* サイトを始めた理由
* 扱うテーマ
* 実際に使っている環境
* どんな読者に向けているか
* 広告リンクの扱い方
* noteやGitHub Pagesの運用方針

例文です。

```text id="h0h3lu"
このサイトでは、Ubuntu、ローカルAI、Obsidian、Hermes Agent、GitHub Pagesを実際に使いながら、無料でAI活用と副業サイト運営を試す過程を記録しています。

記事には広告・アフィリエイトリンクを含む場合がありますが、実体験や公式情報を確認し、誇大表現を避ける方針で運営します。
```

## 広告・アフィリエイト表記ページに書くこと

アフィリエイトを行うなら、広告表記ページは必ず作ります。

例文です。

```markdown id="pq3jw7"
# 広告・アフィリエイト表記について

当サイトでは、記事内に広告・アフィリエイトリンクを含む場合があります。

リンク経由で商品やサービスを購入・申し込みいただいた場合、運営者に報酬が発生することがあります。

ただし、紹介内容は実際の利用経験、公式情報、調査内容をもとに作成し、読者に不利益となる誇大表現や根拠のない断定を避ける方針です。

価格、仕様、キャンペーン内容、成果条件は変更される場合があります。

実際に利用する場合は、必ず公式サイトで最新情報をご確認ください。
```

各記事の冒頭にも、次を入れます。

```text id="owq1t5"
※この記事には広告・アフィリエイトリンクを含む場合があります。
```

広告であることを分かりやすく示すことは、読者の信頼を守るためにも重要です。

## 収益導線の作り方

副業サイトとして収益化するには、記事の中に自然な導線を作ります。

最初から広告リンクを貼りすぎる必要はありません。

流れは次のとおりです。

```text id="pxec0j"
体験記事
↓
手順記事
↓
必要なもの一覧
↓
ASP比較記事
↓
広告リンク
```

たとえば、UbuntuでローカルAI環境を作る記事なら、次のような導線になります。

```text id="j70iwh"
Ubuntu環境構築でつまずいた
↓
USBメモリや外付けSSDが必要だった
↓
バックアップの重要性を感じた
↓
必要なもの一覧を作る
↓
楽天・もしもで商品リンクを検討する
```

GitHub Pagesの記事なら、次のような導線です。

```text id="binm6h"
無料でサイトを作る
↓
記事が3〜5本できる
↓
ASP登録を検討する
↓
A8.net、もしも、楽天を比較する
```

大切なのは、「売りたい商品」から記事を作らないことです。

## noteからGitHub Pagesへ誘導する方法

noteでは、読みやすい体験談を書きます。

GitHub Pagesでは、詳しい手順や比較表を置きます。

導線は次のようにします。

```text id="x04563"

GitHub Pages：
```

note記事の末尾に、次のような文言を入れます。

```text id="i8qb8o"

```

この形にすると、noteは入口、GitHub Pagesは詳しい資料として使えます。

## 自己改善の仕組み

副業サイトは、作って終わりではありません。

反応を見ながら改善します。

改善の流れは次のとおりです。

```text id="zkljmb"
記事公開
↓
Search Consoleで表示回数を見る
↓
CTRを見る
↓
ASPレポートでクリックを見る
↓
成果が出た記事を確認する
↓
タイトルや導線を改善する
↓
関連記事を追加する
```

改善ルールは次のようにします。

| 状態                | 改善          |
| ----------------- | ----------- |
| 表示回数があるのにクリックされない | タイトルを改善     |
| クリックされるが読まれない     | 冒頭を改善       |
| 読まれるが広告クリックがない    | CTAを改善      |
| 広告クリックはあるが成果がない   | 商品選定を見直す    |
| 成果が出た             | 関連記事を追加     |
| 古い情報がある           | 公式情報を確認して更新 |

この改善を週1回行えば、無料サイトでも少しずつ育てられます。

AIには改善案を出させ、実際の公開や広告リンク変更は人間が確認します。

## FAQ

### Q1. WordPressなしでも副業サイトは作れますか？

作れます。

GitHub Pages、note、X、Obsidian、AIを組み合わせれば、無料で記事公開と収益導線の実験ができます。

### Q2. GitHub Pagesだけで十分ですか？

初期段階では十分です。

ただし、本格的な広告管理、デザイン調整、動的機能が必要になったら、WordPressを検討してもよいです。

### Q3. 無料サイトでもアフィリエイトできますか？

ASPや広告主の規約によります。

GitHub Pages、note、SNSなどを媒体として使える場合がありますが、必ず各ASPの最新条件を確認してください。

### Q4. 何記事くらい作ればよいですか？

最初は3〜5本で十分です。

トップページ、プロフィール、広告表記ページ、体験記事、ASP比較記事があると、サイトの形が見えやすくなります。

### Q5. AIで記事を全部作ってもよいですか？

AIは下書きや構成作成に使えます。

ただし、実体験、公式情報確認、広告表記、公開前チェックは人間が行うべきです。

### Q6. いつWordPressへ移行すればよいですか？

記事数、検索流入、収益導線が見えてきた段階で検討すればよいです。

最初から固定費をかけるより、無料で検証してから移行する方が安全です。
