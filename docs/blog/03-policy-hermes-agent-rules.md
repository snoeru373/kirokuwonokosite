# 17. 無料版のHermes Agent運用ルール

## 自動化ルール

1. 新規記事は `draft` に作成する
2. 公開候補は `review` に移動する
3. `published` への移動は人間承認後
4. 広告リンク挿入は人間承認後
5. 記事削除は禁止
6. 料金・条件・規約は公式情報を確認する
7. 出典URLと確認日を記録する
8. 誇大表現を検出したら修正案を出す
9. 「必ず稼げる」「完全放置で稼げる」は禁止
10. 金融・健康・法律は初期収益化対象から外す
