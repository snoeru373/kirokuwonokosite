## TL;DR（結論）

> Ollamaはコマンドラインから、Open WebUIはブラウザのチャットUIからAIモデルを動かせる無料ツール。
> 7B〜13Bパラメータのモデルなら個人PCでも十分実用できます。ただし400GB以上のファイル処理やリアルタイム検索には不向きです。

## やり方・手順の詳細

### ステップ1 — Ollamaのインストール

```bash
# 公式サイトからインストーラーを取得
curl -fsSL https://ollama.com/install.sh | sh

# モデルをダウンロード (例: Llama3.1 8B)
ollama pull llama3.1
```

### ステップ2 — Open WebUIとの連携

Dockerを使わない場合:

```bash
# pipでOpen WebUIをインストール
pip install open-webui

# 起動
open-webui serve --port 8080
```

Dockerを使う場合（推奨）:

```bash
docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/root/.open-webui \
  --name open-webui \
  ghcr.io/open-webui/open-webui:main
```

ブラウザで `http://localhost:3000` を開くとチャットUIが起動します。

### ステップ3 — 実際に使ってみて分かったこと

- **テキスト生成**: プロンプト次第で良い回答が得られる。日本語でもそれなりに対応
- **ファイル処理**: ドラッグ&ドロップしたPDFの要約が便利。ただし300ページ以上は時間がかかる
- **速度**: VRAM48GBあれば数秒以内に回答。VRAM8GBの場合は10〜30秒程度
- **リアルタイム検索**: できません。インターネット情報を拾うには別のツールが必要

## FAQ

### Q1. Ollamaは無料ですか？
A: はい。インストールと利用は無料です。クラウドAPIの利用料もかかりません。

### Q2. どんなPCなら動きますか？
A: メモリ8GB以上でCPU推論可能です。VRAMがあればGPU加速で快適になります。
